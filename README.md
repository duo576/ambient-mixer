# 氛围音播放器

多轨氛围音混音播放器：任意多条音轨**同时播放、互不打断**，每条音轨独立控制进度、音量、循环。支持拖拽自定义排序，列表与设置本地持久化，刷新/重启不丢。

两个版本共用同一个播放器内核（`web/player.html`）：

- **网页版** —— 单文件，浏览器直接打开即可使用
- **macOS 菜单栏 App** —— 原生 Swift + WKWebView，菜单栏波形图标一键开关窗口

## 功能

- 点击任意音轨的播放按钮即开始播放，其他音轨不受影响，可叠加任意多条
- 每条音轨独立：播放/暂停、可拖动进度条（含当前/总时长）、音量滑块（带百分比）、循环开关、移除
- 拖动文件名左侧手柄自定义排序
- 顶部「全部播放 / 全部暂停」一键控制
- 音轨列表、音量、顺序、循环状态持久化在本地（IndexedDB + localStorage）
- 添加方式：按钮选择文件，或直接把文件拖进窗口

## 网页版

直接用浏览器打开 `web/player.html`。

## macOS 菜单栏 App

- 菜单栏波形图标：**左键**显示/隐藏窗口，**右键**弹出菜单（显示/隐藏、退出）
- 单实例运行：重复启动会激活已有实例
- 无 Dock 图标（LSUIElement），关窗不退出，图标常驻菜单栏

构建（需要 Xcode Command Line Tools，无需完整 Xcode）：

```bash
./macos/build.sh
# 产物: build/氛围音播放器.app
cp -R "build/氛围音播放器.app" /Applications/
```

## 已修复：假 .mp3（流式分片 MP4）导致时长只显示几秒

网上不少文件扩展名是 `.mp3`，实际容器是**流式分片 MP4**（`ftyp` + `moof/mdat` 分片，`moov` 中时长声明为 0）。

浏览器会信任文件自带的 MIME 类型：`.mp3` 给出 `audio/mpeg`，于是用 MP3 解析器去读 MP4 数据，结果：

- 时长按已解析碎片随机估值（实测同一文件分别估出 1526 / 2287 / 3428 秒，真实值 28028 秒）
- 播放到估值就硬停止并循环，进度条"只显示几秒"

修复方式：**添加文件时读取文件头嗅探真实容器**（第 4–8 字节为 `ftyp` 即 MP4），按真实类型（`audio/mp4`）交给解码器。验证结果：时长精确到秒（读取 sidx 索引）、全范围可拖动（已测 1 小时 23 分、7 小时 30 分处精确跳转）。
